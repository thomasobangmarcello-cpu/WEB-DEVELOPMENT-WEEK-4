
# SpendWise Dashboard Shell

## 1. Project Description

SpendWise is a modern personal finance dashboard designed to help users visualize and manage their monthly expenses.

This project focuses on building a clean, responsive dashboard interface using HTML5 and CSS3.

The dashboard displays financial summaries and expense categories using realistic static financial information.

## 2. Project Objectives

The main objectives of this project are:

- Build a modern financial dashboard layout.
- Create a sidebar navigation menu.
- Design a dashboard header.
- Display at least six financial category cards.
- Practice CSS Grid and Flexbox.
- Use CSS custom properties for consistent theming.
- Implement responsive design for mobile devices.
- Add hover and keyboard focus animations.
- Implement an optional dark theme.

## 3. Technologies Used

- HTML5 – For the dashboard structure.
- CSS3 – For styling and layout.
- CSS Grid – For the overall dashboard and card layouts.
- Flexbox – For arranging content inside dashboard components.
- CSS Variables – For managing theme colors.
- Media Queries – For responsive design.
- Visual Studio Code – For writing and editing code.
- Google Chrome – For testing the dashboard.

## 5. Dashboard Features

### Sidebar Navigation
The sidebar contains:
- Dashboard
- Transactions
- Budgets
- Savings
- Settings

### Financial Summary
The dashboard displays:
- Total Monthly Budget
- Total Spent
- Remaining Balance

### Expense Categories

The dashboard contains six financial category cards:

1. Food
2. Transport
3. Rent
4. Entertainment
5. Savings
6. Utilities

Each card displays sample spending information, a budget or savings target, and a progress indicator.

## 6. CSS Techniques Implemented

### CSS Grid
CSS Grid is used to create the overall dashboard structure, financial summary layout, and expense category cards.

### Flexbox
Flexbox is used to arrange the sidebar navigation, header content, profile information, and individual category card elements.

### CSS Custom Properties
CSS variables are defined inside the :root selector to maintain a consistent color theme.

### Responsive Design
A media query at a maximum width of 767px changes the dashboard into a single-column layout for smaller screens.

### Micro-interactions
Dashboard cards use smooth hover and keyboard focus animations with transform and box-shadow.

The animation duration is 200 milliseconds.

### Dark Theme
The project includes an optional dark theme using the prefers-color-scheme media query.

## 7. How to Run the Project

1. Download or open the SpendWise project folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click inside the HTML editor.
5. Select Open with Live Server.
6. The dashboard will open in your web browser.

You can also open index.html directly in Google Chrome.

## 8. Responsive Design Testing

The dashboard can be tested using Google Chrome Developer Tools.

Steps:
1. Open the dashboard in Google Chrome.
2. Right-click and select Inspect.
3. Click the Toggle Device Toolbar icon.
4. Test different screen sizes.

Recommended screen sizes:

- Desktop: 1440px
- Tablet: 1024px
- Mobile: 390px

## 9. Project Limitations

This project is a visual dashboard prototype.

- Financial information is static.
- Navigation links are not connected to functional pages.
- No database is connected.
- No financial calculations or transactions are processed.
- No JavaScript functionality is implemented.
